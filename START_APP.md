# 🚀 Start App - Quick Reference

## Easiest Way (2 Terminal Windows):

### Terminal 1 - Backend:
```bash
cd /Users/nicholas/Documents/Build-Profit-Solutions
./start-backend.sh
```

### Terminal 2 - Mobile:
```bash
cd /Users/nicholas/Documents/Build-Profit-Solutions/mobile
npm run dev:lan
```

---

## Alternative: Start Both Automatically (macOS)

This opens 2 separate Terminal windows automatically:
```bash
cd /Users/nicholas/Documents/Build-Profit-Solutions
./start-both.sh
```

---

## One Window (Both Services Together):

Starts both in the same terminal window:
```bash
cd /Users/nicholas/Documents/Build-Profit-Solutions
./start-app.sh
```
*(Press Ctrl+C to stop both)*

---

## What You'll See:

✅ **Backend**: Running on `http://localhost:3001`  
✅ **Mobile**: Expo QR code appears in terminal/browser  
📱 Scan QR code with Expo Go app or press `i` (iOS) / `a` (Android)

---

## Stop Everything:

Press `Ctrl+C` in the terminal(s) where services are running.
